Full-Stack

FitCore

FitCore is a modern web-based Smart Gym Management System developed to simplify and automate the daily operations of a fitness centre. The system provides an intuitive platform for gym administrators, trainers, and members to manage memberships, workout schedules, attendance, payments, and fitness progress efficiently.

The frontend of the application was developed using the React.js framework, providing a fast, responsive, and user-friendly interface with reusable components. The backend was built with Node.js and Express.js, which handle business logic, RESTful APIs, authentication, and communication with the database. MongoDB serves as the database, offering a flexible NoSQL solution for storing user profiles, membership information, workout plans, payment records, and other gym-related data.

React.js Node.js Express.js MongoDB
